# 🎬 Kino XII

Kino XII is a modern cinema ticket booking application built with Next.js, React, and TypeScript.

### 🌐 Live Demo

**[Visit Kino XII](https://kino-aia92tjb6-teonazavs-projects.vercel.app/)**

## Features

- Browse featured and now-playing movies
- Explore movie details and available sessions
- Filter cinema sessions
- User authentication and profile management
- Interactive seat selection and ticket booking
- Checkout and payment flow
- View booking history and manage tickets
- Responsive design

## Tech Stack

- **Next.js** – App Router
- **React**
- **TypeScript**
- **Tailwind CSS**
- **TanStack Query**
- **Axios**
- **React Hook Form**
- **Framer Motion**
- **Swiper**

## Getting Started

Clone the repository:

```bash
git clone https://github.com/TeonaZav/kino-xii.git
```

Navigate to the project directory:

```bash
cd kino-xii
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
